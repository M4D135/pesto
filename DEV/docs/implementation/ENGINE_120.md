## Module et build reproductible

```powershell
# Dans DEV, sur une copie source non signée
.\tools\Build-PestoEngineModule.ps1
.\tools\Build-PestoEngineModule.ps1 -Check
Import-Module .\wad\Pesto.Engine.psd1
Get-PestoEngineInfo
Get-PestoEngineWorkerScriptBlock -Name Direct
```

Le générateur produit `Pesto.Engine.Runtime.ps1`, `.psm1`, `.psd1` et `.build.json`. Ce dernier contient les sources et leurs empreintes, les dépendances, les workers et les exports. Le chargeur `.psm1` compare l’empreinte exacte du runtime avant de charger ses définitions ; une altération est refusée.

La fermeture exclut les fonctions UI de bootstrap (`Write-Log`, `Confirm-YesNo`, etc.) pour ne pas écraser les stubs définis dans les workers. Le build refuse aussi une dépendance produit absente de la liste des workers GUI. Les fonctions nécessitant Windows restent des fonctions ; leur présence dans le module ne les rend pas exécutables sous macOS.

Pour une copie Authenticode : générer d’abord, signer le runtime, rebinder son empreinte dans le module et les métadonnées, puis signer les chargeurs/manifeste PowerShell ; enfin refaire le manifeste et le lanceur natif de distribution. Le contrôle de génération de la source non signée ne se substitue pas à la vérification de cette copie signée.
