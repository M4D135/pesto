# Pesto 17.0-RC21 : état exact des 90 propositions

## Lire ce tableau

Ce suivi compare le code RC21 au plan RC20. **Les 90 points ne sont pas tous terminés et aucun n’est déclaré accepté sur Windows à partir des tests Linux.**

- **Livré** : code ajouté et raccordé ; l’acceptation Windows reste à obtenir.
- **Option livrée** : code présent, activation explicite et conditions d’entreprise nécessaires.
- **Consolidé / Conservé** : fonction antérieure maintenue ou renforcée, pas une nouveauté inventée.
- **Partiel** : contenu et limite détaillés ; le reste n’est pas silencieusement considéré fait.
- **Tests fournis / Recette à exécuter / Outillage, à autoriser** : matériel livré, exécution ou autorisation encore absente.
- **Non livré** : fonction non intégrée. La jonction hors connexion djoin en fait partie.

Le détail des 69 tests Python, 300 contrôles portables et des tests C réellement exécutés figure dans RC21_VALIDATION.md. Ces preuves ne remplacent pas PowerShell 5.1/WPF/UAC/AD. Aucune modification du domaine du client n’a été exécutée.

## Limites les plus importantes avant diffusion

La coordination fonctionne uniquement entre clients effectivement configurés avec le même registre autorisé. La signature exige le certificat de l’organisation. Les réparations de protection restent limitées aux situations prouvées ; un crash ambigu ne justifie pas un déblocage arbitraire. Les imports historiques sont manuels et bornés, pas exhaustifs. Les accès aux fichiers ne sont pas certifiés résistants à toutes les courses de liens/ACL. La mise à jour conserve son rollback sur exception, pas une transaction universelle après panne électrique.

Le transport djoin, le résolveur CMDB d’étiquettes et la réservation collective de plages ne sont pas ajoutés. Les tests Windows, les scénarios AD réels, l’accessibilité et l’endurance sur parc représentatif restent à exécuter.
